# Дорожня карта (рішення рецензента Fable, 11.11.2026)

Відгук викладачки збираємо після етапу 5 (коли з'явиться таблиця оцінок) — він має пріоритет
над рішеннями нижче.

## Загальні правила паралельної роботи
- **Спершу специфікація:** перед етапом Fable пише `docs/specs/stage-N.md` (рішення, сигнатури сервісів, хто які файли редагує).
- **До 3 агентів одночасно**, зазвичай 2 (автор не обмежує кількість — це власне обмеження Fable заради економії токенів). Не паралелимо дрібні шматки (<150 рядків) і роботу, поки не зафіксовано API сервісу.
- **Спільні файли редагує лише оркестратор:** `ui/main_window.py`, `ui/theme.py`, `ui/widgets.py`, `app.py`, `models/__init__.py`, `requirements*.txt`, `README.md`, `CLAUDE.md`.
- **Один власник міграцій на етап** (він же власник `models/*.py`).
- **Одна гілка, один PR, одна рецензія Fable на етап.** Повний `pytest` — один раз перед рецензією.
- **Моделі:** UI — sonnet (не haiku); конфіги, документація, шаблонні тести — haiku; основна модель — лише «клей».

| Етап | Мета | Агенти | Вартість |
|---|---|---|---|
| 3 | Класи та учні | sonnet (тести) + sonnet (UI) | M |
| 4 | CI на GitHub, зафіксовані версії, журнал помилок у файл | 2 × haiku | S |
| 5 | Журнали, уроки, таблиця оцінок із введенням з клавіатури; CASCADE → RESTRICT для оцінок | sonnet (БД+сервіси) + sonnet (UI) | L |
| 6 | Підсумкові оцінки, середні, експорт у Excel | 2 × sonnet | M |
| 7 | Резервні копії, зміна пароля, захист від підбору | 3 × sonnet | M |
| 8 | Інсталятор (PyInstaller + Inno Setup + вбудований PostgreSQL без прав адміністратора) | 1 × sonnet; пробна версія паралельно з етапом 5 | L |
| 9 | Матеріали для диплому: ER-діаграма, схема шарів, сценарії, приватність, тести UI | haiku + sonnet | S–M |

Порядок: 4 зараз → 5 (+ пробний інсталятор) → 6 → 7 → завершення 8 → 9.

## Ключові продуктові рішення
- **Етап 5:** семестр визначається датою (вер–гру → 1, січ–чер → 2); кілька уроків в один день дозволено.
  - Клавіші в таблиці: цифри — оцінка, `н` — відсутній, `х` — хворів, `з` — запізнився, `Del` — очистити, `Enter` — вниз, `Tab` — вправо, `F2` — коментар.
  - Кожна клітинка зберігається одразу. `Ctrl+N` — новий урок на сьогодні.
- **Етап 6:** середнє з точністю до 0,1. Запропонована семестрова оцінка — середнє, округлене за правилом «0,5 — вгору»; викладачка підтверджує або змінює. Тематичні оцінки — поза межами (обмеження).
- **Етап 7:** копія через `pg_dump`; автокопія при виході (останні 10); відновлення з підтвердженням і попередньою копією. Забутий пароль означає відновлення з копії під новим акаунтом — «чорного ходу» немає.
- **Етап 8:** PostgreSQL запускається самим застосунком у `%LOCALAPPDATA%`, на 127.0.0.1, з випадковим паролем. Перевірку на чистому комп'ютері робить автор.
